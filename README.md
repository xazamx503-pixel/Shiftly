# Shiftly Public Pages

Static GitHub Pages site designed to match the Shiftly in-app About / legal screens.

## Public routes after GitHub Pages is enabled

If the repository is named `shiftly`, the URLs will be:

- `https://YOUR-USERNAME.github.io/shiftly/`
- `https://YOUR-USERNAME.github.io/shiftly/privacy/`
- `https://YOUR-USERNAME.github.io/shiftly/support/`
- `https://YOUR-USERNAME.github.io/shiftly/terms/`
- `https://YOUR-USERNAME.github.io/shiftly/privacy-choices/`

## Recommended App Store Connect URLs

- Privacy Policy URL → `/privacy/`
- Support URL → `/support/`
- Terms of Use → `/terms/`
- Privacy Choices → `/privacy-choices/` (optional)

## Publishing

1. Create a public GitHub repository.
2. Upload all files/folders from this package to the repository root.
3. GitHub → Settings → Pages.
4. Build and deployment → Deploy from a branch.
5. Branch: `main`, Folder: `/ (root)`.
6. Save and wait for the public URL.

The `.nojekyll` file is included intentionally.
